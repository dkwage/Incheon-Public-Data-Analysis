# 인하대 후문 과거 점포·인허가 자료 확보

확인일: 2026-09-15. 현재 후문 경계의 음식 업종은 296/534개(55.4%)다. 음식점 관련 인허가를 먼저 확보하고 다른 업종으로 확대한다.

## 1. 과거 점포 스냅샷: 같은 경계의 점포 구조 비교

공식 페이지: https://www.data.go.kr/data/15083033/fileData.do

페이지의 ‘주기성 과거 데이터’에서 원하는 기준일을 선택해 다운로드한다. 현재 과거 목록 49건을 확인했다.
우선 2024-06-30, 2025-06-30을 확보해 보유한 2026-06 자료와 같은 계절을 비교한다.
분기 추이는 2024-03-31부터 2026-03-31까지 추가한다. 목록의 2025-10-30은 임의로 9월 말 자료로 바꾸지 않는다.
등록일 대신 데이터 기준일을 기록하고 ZIP의 인천 파일을 사용한다.

처리 순서: 원본 보존 → 기준일·코드체계 확인 → 미추홀구 필터 → 같은 사용자 경계로 공간 추출 → 업종별 점포 수 비교.
파일과 현재 API의 수집·정제 차이도 점검한다. 스냅샷에서 사라진 점포는 ‘미관측’이며 폐업으로 확정하지 않는다.
상가업소번호는 과거 개편 시 재생성된 이력이 있으므로 모든 연도에서 같은 ID라고 가정하지 않는다.
과거 변경 공지: https://www.data.go.kr/dataset/15012005/openapi.do?lang=ko

## 2. 인허가: 신규 인허가·폐업 신고의 시계열

2026년 공공데이터포털 통합 개방을 확인했다. 기존 LOCALDATA 홈페이지 경로보다 아래 현재 페이지를 사용한다.
공식 통합 안내: https://www.aigov.go.kr/promotion/notice/64

| 우선 자료 | 파일 페이지 | API 페이지 |
|---|---|---|
| 일반음식점 | https://www.data.go.kr/data/15045016/fileData.do | https://www.data.go.kr/data/15154916/openapi.do |
| 휴게음식점 | https://www.data.go.kr/data/15006730/fileData.do | https://www.data.go.kr/data/15154921/openapi.do |
| 제과점영업 | https://www.data.go.kr/data/15044973/fileData.do | https://www.data.go.kr/data/15155252/openapi.do |

일반음식점 파일 페이지의 현재 다운로드 연결은 https://file.localdata.go.kr/file/general_restaurants/info 이다.
이번 브라우저에서는 이 연결이 403으로 차단되어 실제 인허가 원본은 아직 확보하지 못했다. API는 별도 활용신청 경로가 있고 일반음식점은 무료·개발단계 자동승인으로 안내된다. 기존 공공데이터 키가 있어도 서비스 이용 권한은 별도 확인이 필요하다.

### 받아야 할 범위

- 인천광역시 미추홀구, 모든 영업상태(영업·폐업·휴업 등), 전체 인허가일 범위.
- 분석기간을 2024~2026년으로 잡더라도 다운로드 단계에서 인허가일을 2024년 이후로 제한하지 않는다. 이전에 개업해 최근 폐업한 업소가 빠진다.
- 주소의 옛 ‘남구’ 표기가 남은 과거 행도 코드·좌표로 확인한다.
- 필요한 항목: 업종/개방서비스ID, 관리번호, 사업장명, 인허가일자, 인허가취소일자, 영업상태·상세상태, 폐업일자, 휴업·재개업일자, 도로명/지번주소, 좌표X/Y, 최종수정일, 갱신일.
- 실제 필드명과 제공 범위는 선택한 API 명세에서 확인한다. 좌표 없는 행은 제외 건수를 기록하고 주소로 후속 확인한다.

### 공간·기간 처리 원칙

일반음식점 공식 명세는 EPSG:5174를 명시한다. 사용자 GeoJSON의 경도·위도와 좌표계가 다르므로 WGS84로 변환한 뒤 경계 안 업소를 뽑는다. 다른 업종도 각각 명세를 확인한다.
인허가 자료의 관리번호와 공공 상가업소번호는 다른 식별자다. 상호만으로 자동 병합하지 않는다.

월별로 먼저 집계할 값:

1. 인허가일 기준 신규 인허가 건수(실제 개점일과 다를 수 있음)
2. 폐업일 기준 폐업 신고 건수
3. 신규 인허가 건수 − 폐업 신고 건수(신고 흐름 차이; 영업점포 순증과 동일하지 않음)
4. 누락 날짜·좌표·상태 불일치 및 중복 관리번호 검토 건수

현재 추출본으로 과거 영업점포 수를 복원하면 폐업 업소 보존 범위, 이전 주소, 휴업·재개업 이력 누락에 영향을 받는다. 자료의 역사적 완전성 확인 전 폐업률·생존율 분모를 만들지 않는다.
음식점 인허가 결과를 전체 상권 폐업률로 일반화하지 않는다. 현재 음식 업종 296개와 인허가 건수도 일대일 대응하지 않는다.

## 3. 다운로드가 계속 막힐 때 구청 요청 문안

아래는 요청 초안이며 발송하지 않았다.

> 인하대 후문 상권 현황 진단을 위해 미추홀구 일반음식점·휴게음식점·제과점영업의 영업 및 폐업 포함 인허가 자료를 요청드립니다. 2024년 1월부터 2026년 최신 완료월까지의 신규 인허가·폐업 추이를 분석할 예정이며, 이전 인허가 후 해당 기간에 폐업한 업소도 포함해야 합니다. 관리번호, 업종, 인허가·폐업·휴업·재개업일, 영업상태, 주소, 좌표 및 좌표계, 기준일을 포함한 CSV 제공 가능 여부와 과거 폐업자료의 보존 범위를 확인 부탁드립니다. 대표자 개인정보는 필요하지 않습니다.

- 학사일정: 공식 홈페이지 2024~2026년 수집·정규화 완료. 별도 사용안내 참조.
