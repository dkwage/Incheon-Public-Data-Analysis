# 인하대 후문 문제 진단 계획

## 목적

인하대 후문은 선정된 조사 대상이다. 쇠퇴나 활성화 필요성은 아직 확인되지 않았다.
현황 → 문제 여부 → 원인 후보 검증 → 조건부 대응 → 시행 후 평가 순서로 진행한다.

## 현재 확보 자료와 판단 범위

| 자료 | 가능한 판단 | 부족한 부분 |
|---|---|---|
| 2026년 6월 미추홀구 점포 18,885개 | 직접 설정한 경계의 업종·점포 분포, 구 대비 특화 | 단일 시점으로 폐업률·쇠퇴 판단 불가 |
| 2026년 6월 버스 승하차·정류장 좌표 | 대중교통 접근 여건 | 후문 방문자·소비전환율 아님 |
| 2026년 6월·8월 주민등록인구 | 관련 행정동의 주민 구성 | 방문객·학생 규모 및 장기 추세 아님 |
| 신한카드 공개 명세·마스킹 샘플 | 집계 코드와 결과표 설계 | 후문 실제 매출 진단 불가 |

## 추가 자료 우선순위

1. 카드 읍면동 코드 정의와 대응 경계: 행정동/법정동 구분을 확인하고 후문과 겹치는 동을 연결한다.
2. 현장 반복 관찰·상인/이용자 의견: 구간·요일·시간·날씨·응답 수를 기록한다. 일시 휴무와 공실을 구분한다.
3. 개폐업 이력·과거 점포 자료: 확보 가능한 업종·기간·지역을 확인한다. 인허가 자료의 일부 업종 결과를 전체 상권으로 일반화하지 않는다.
4. 카드 본자료: 관련 동과 비교 지역의 월별 결제금액·건수를 우선 분석한다. 가능하면 24~36개월의 동일한 정의를 가진 자료를 사용한다.
5. 학사일정·행사·지원사업 이력: 계절성 및 다른 원인 후보를 검토하는 데 사용한다.

## 판단과 후속 단계

- 문제 진단: 과거 같은 계절·유사 지역과의 차이 및 현장 근거를 함께 확인한다. 방학 감소나 업종 집중만으로 문제라고 판정하지 않는다.
- 원인 검증: 확인된 문제에 대해 가능한 설명과 반대 근거를 기록하고, 관련 시간·구간의 현장 관찰 및 의견 조사로 좁힌다. 관찰자료만으로 인과관계를 확정하지 않는다.
- 대응: 문제·원인 근거가 확보된 항목에 대해 담당 부서·상인과 시행 가능성을 검토한다.
- 평가: 실제 사업·시행일·대상·평가지표가 정해진 뒤 사전 측정을 확보한다. 비교집단과 사전 추세 등 조건을 충족할 때 효과 분석을 검토한다.
- 판단 결과는 ‘문제 근거 있음 / 현재 확인 범위에서 뚜렷한 문제 근거 없음 / 판단 유보’로 구분한다.

## 경계 편집 지도 사용법

프로젝트 루트에서 아래 서버를 실행한 뒤 브라우저에서 <http://127.0.0.1:8765/inha_boundary_editor.html>을 연다.
배경지도와 Leaflet 로딩에 인터넷이 필요하다. HTML 파일을 직접 열면 지도 요청의 Referer가 빠져 OSM 타일이 403으로 차단될 수 있다.

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory outputs
```

1. ‘경계 그리기’를 누르고 지도에서 가장자리를 따라 꼭짓점을 순서대로 클릭한다.
2. ‘그리기 종료’를 누른다. 점을 끌어 위치를 수정하거나 ‘마지막 점 취소’를 사용한다.
3. 포함·제외 이유를 입력하고 ‘GeoJSON 저장’을 누른다.
4. 다운로드한 `inha_boundary.geojson`을 이 프로젝트의 `data` 폴더에 넣는다.

사용자가 저장한 경계를 기준으로 구 전체 점포 원자료를 재집계하는 것이 다음 작업이다.
지도에 표시된 점포는 기존 후보지별 1km 범위 자료이며, 그 범위 밖이 비어 보여도 점포가 없다는 뜻은 아니다.
이 지도는 경계 편집·내보내기를 제공한다. 기존 경계 파일 불러오기와 자동 재집계는 아직 제공하지 않는다.
선 교차·중복점·일직선 꼭짓점이 있으면 저장을 막는다. 경계는 공식 정책경계가 아닌 연구자 설정 범위다.

보고 지도를 갱신한 경우 프로젝트 루트에서 `python3 build_boundary_map.py`로 편집 지도를 다시 생성한다.
브라우저 콘솔의 `boundarySelfCheck()`로 경계 유효성 검사를 실행할 수 있다.

## 소비자료 연결 원칙

카드의 읍면동 집계는 후문 다각형으로 분할할 수 없다. 동 전체 소비는 배경 근거이며 후문 현장 자료로 추가 확인한다.
공공 점포와 카드의 업종을 공통 분류로 맞추고 동일 동·기간·업종 범위에서 비교한다.
동 매출을 후문 점포 수로 나누거나 점포 비중으로 배분하지 않는다.
공개 카드 샘플은 월·공휴일 구분·시간대 구분을 포함하지만 날짜·요일은 없다. 별도 확인 전 요일 분석을 확정하지 않는다.

공개 명세 확인 출처: https://dsz.kdata.or.kr/svc/data/search.do 에서 ‘지역별매출’ 검색 → 미리보기.
지도 기능은 기존 Leaflet API를 사용한다: https://leafletjs.com/reference
