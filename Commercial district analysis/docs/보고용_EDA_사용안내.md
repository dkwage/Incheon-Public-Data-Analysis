- 노트북: `briefing_eda_20260909.ipynb` — 실행 결과와 그림 저장 완료.
- 실제 지도: `outputs/briefing_map.html` — OpenStreetMap 위에 상권별 점포·반경·정류장·시장 대표점 표시.
- 인터넷 없는 회의: 노트북의 저장된 지도 화면 또는 `outputs/briefing_map_overview.jpg` 사용.

## 발표 순서 (약 10분)

1. 1분: 데이터 기준월과 할 수 있는 판단·할 수 없는 판단.
2. 3분: 실제 지도에서 세 상권의 중심·500m 범위 확인. 지하상가, 철도, 대학 정문·후문, 인하대역 포함 여부 논의.
3. 3분: 점포 규모·업종 구성·LQ와 관련 동 연령구성 비교.
4. 1분: 버스 접근성은 철도 미포함 참고자료라는 한계 설명.
5. 2분: 공식 경계·사업 이력·카드자료 단위 등 협조사항 결정.

## 실행

기존 `.venv` Python 커널로 노트북 전체 실행. 추가 Python 패키지나 인증키는 필요 없다. 지도 HTML은 Leaflet CDN과 OpenStreetMap 타일을 불러오므로 인터넷이 필요하다. 신뢰하지 않는 노트북의 HTML 출력은 뷰어에서 차단될 수 있으므로, 그 경우 별도 HTML을 브라우저에서 연다.

로컬 HTTP 미리보기:

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory outputs
```

`http://127.0.0.1:8765/briefing_map.html` 접속. 지도 타일은 브라우저가 현재 화면에 필요한 것만 요청한다. 대량 다운로드·오프라인 타일 수집은 하지 않았다. 저장된 지도 이미지는 화면 캡처다.

## 검증

보고용 계산 셀 실행 및 구성비 합계·지도 점포 수·인구 단위 일관성 검증 통과. 브라우저에서 배경 타일 로딩·상권 이동·점포 팝업·점포 레이어 토글 확인. 화면 캡처와 업종 그래프 육안 확인. 지도 캡처 시 브라우저 캡처 도구가 Leaflet 애니메이션 요소를 숨기는 현상이 있어 캡처 페이지에서만 애니메이션 클래스를 제거했다. 배포 HTML의 지도 동작은 그대로 유지했다.

주요 해석 제한: 원형 반경은 정책경계·보행권이 아니며, 관련 행정동 인구는 상권 거주인구가 아니다. LQ는 특화 정도이며 과밀·공백·수익성의 증거가 아니다. 소비·철도·공실·사업효과 자료는 미포함.
