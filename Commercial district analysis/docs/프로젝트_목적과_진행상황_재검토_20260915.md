# 미추홀구 상권 활성화 분석: 목적과 진행 상황 재검토

검토일: 2026-09-15. 제안서 0904 ver1.1, 실데이터·회의용·합성 카드 노트북, 인하대 후문 경계 결과, 진단·현장조사 계획과 현재 파일을 검토했다. 이번 검토는 연구 설계와 산출물의 정합성 검토이며 모든 분석 코드를 다시 실행한 감사는 아니다. 점포 수·업종 비중·현장 서식 상태는 실제 파일에서 재집계했다.

## 1. 목적을 다시 고정한다

**미추홀구의 정책 대상지로 선정된 인하대 후문에서, 사람들의 이용 흐름과 소비 특성을 파악하여 어디에·언제·누구를 대상으로·무엇을 지원하면 상권 이용과 소비에 도움이 될지 제안한다.**

- 미추홀구 전체는 정책·비교 맥락, 인하대 후문은 이번 상세 분석과 전략 적용 대상이다. 후문 사례를 구 전체 상권의 특성으로 일반화하지 않는다.
- 활성화는 쇠퇴 대응뿐 아니라 기존 강점 확대, 이용 불편 해소, 특정 시기 영업 안정화도 포함한다. 반드시 쇠퇴를 입증해야만 전략을 제안할 수 있는 것은 아니다.
- 연구 질문은 ‘문제가 있는가?’에서 끝나지 않는다. ‘확인된 강점·불편·미충족 수요 중 어떤 항목을 공공사업으로 개선할 수 있는가?’까지 이어져야 한다.
- 최종 성과는 그래프 수나 분석기법 수가 아니라, 근거와 시행 조건이 명시된 소수의 전략 및 평가계획이다. 실제 사업 시행 전에는 매출 개선 효과를 달성했다고 표현하지 않는다.

## 3. 설계에서 가장 큰 공백

### 3.1 실제 유동인구가 아직 없다

버스 승하차는 교통 이용 건수다. 도보·자전거·차량 방문, 상권 내부 이동, 통과와 목적 방문을 모두 설명하지 못한다. 주민등록인구도 실제 방문객 자료가 아니다.

정밀 유동자료의 확보 가능성을 확인하되, 현재 준비된 고정 지점 반복 관찰을 먼저 활용한다. 진입부·중심거리·내부 골목에서 같은 시간 길이의 방향별 통행을 기록하고, 방문 목적·이용 점포·이동수단은 자발적 응답 조사로 보완한다. 결과는 ‘관찰 지점의 통과 건수’이며 상권 전체 고유 방문객 수로 확장하지 않는다.

### 3.2 실제 소비자료가 없고 공간 단위도 맞지 않는다

현재 공개 명세에는 읍면동 코드가 있으나 가맹점명·ID·주소·좌표가 없다. 행정동/법정동 구분과 공식 코드 정의를 확인해야 한다. 맞춤 경계 집계가 가능한 별도 제공 방식이 있는지도 확인 대상이다.

후문 점포 주소는 용현1·4동으로 연결되지만, 후문 534개와 동 전체 1,349개는 같은 범위가 아니다. 음식점 비중도 후문 55.4%, 동 전체 39.2%, 경계 밖 28.6%로 다르다. 동 소비를 후문 소비로 간주하거나 점포 비중으로 배분할 근거가 없다.

**이름이 없어도 업종·시간대·연령별 집계 분석에는 카드 데이터가 유용하다. 핵심 제약은 점포명 자체보다 분석 대상과 집계 공간의 불일치다.**

운영할 분석 단위:

| 단위 | 자료와 역할 | 결과 표현 |
|---|---|---|
| 후문 사용자 경계·관찰 구간 | 점포, 통행 관찰, 이용자·상인 의견 | 구간별 이용 특성·실행 위치 |
| 카드에서 확정되는 읍면동 | 실제 소비 추이·구성, 동일 단위의 비교지역 | 관련 동의 소비 배경 |
| 대학·전국 등 외부 맥락 | 학사일정, 필요한 소비 트렌드 | 확인된 패턴의 설명 후보 |

서로 다른 단위의 자료는 각각 집계한 결과와 해석을 연결한다. 한 테이블에 결합했다는 이유만으로 같은 사람·같은 공간을 측정한 것이 되지는 않는다. 버스 건수로 카드 건수를 나눈 값은 소비전환율이 아니다. 동일 공간·기간으로 맞추더라도 카드 거래는 사람 수와 달라 직접적인 방문자 구매율이 되지 않는다.

### 3.3 전략을 고르는 질문이 분석기법보다 뒤에 있다

제안서에는 접근성 지수·KDE·LQ·엔트로피·Gi*·AHP-TOPSIS 등이 있으나 각각 어떤 사업 결정을 바꾸는지가 부족하다. 다음을 먼저 정하고 필요한 방법만 사용한다.

1. 이용이 활발한 구간·업종·시간은 무엇인가?
2. 수요가 있어도 이용이 불편하거나 연결되지 않는 구간이 있는가?
3. 소비가 약한 시기·업종은 일반적인 계절 패턴인가, 상대적으로 부진한가?
4. 확인된 항목에 구청·대학·상인 등이 실행할 수 있는 대응은 무엇인가?

소비를 늘릴 여지가 보여도 비용·참여 가능성·기존 사업과의 중복을 확인해야 한다. 여러 구간의 소비를 옮겨 놓은 효과와 상권 전체의 추가 소비도 구별할 필요가 있다.

## 4. 원래 제안서에서 수정할 부분

| 현재 표현·구상 | 검토 결과 | 수정 방향 |
|---|---|---|
| 후보 상권 비교와 순위 | 회의에서 후문 선정 완료 | 후문 내부의 대상·시간·사업 선택을 중심에 둠 |
| 버스 지표 기반 유입·소비전환 | 직접 측정 불가 | 교통 여건 + 현장 통행·목적 조사 + 별도 소비 분석 |
| LQ·다양성에서 과밀·공백 진단 | 구성 지표만으로 수급 불균형 판단 불가 | 특화 구조를 먼저 기술하고 실제 이용 수요·영업 상황 확인 |
| 요일별 중앙값·CV | 현재 카드 명세는 월 단위이며 날짜·요일 없음 | 월별·시간대별 분석부터 확정. 공휴일 코드를 요일로 대체하지 않음 |
| 학기·야간 활성화 | 아직 현지 수요·운영 문제가 검증되지 않음 | 관측되는 강점 또는 불편에 따라 대상 시간 선정 |
| AHP-TOPSIS 지원 순위 | 대안·평가 기준·가중치 근거 미확정 | 우선 근거·실행 가능성·비용·평가 가능성을 병기한 전략표 |
| DID 효과 검증 | 사업·시행일·사전 추세·비교집단 없음 | 지금은 사전 측정과 평가 설계. 조건 확보 후 적용 검토 |

원점 검토 결과, 앞선 진행은 ‘쇠퇴 증거 수집’과 ‘합성자료 결합 예제’에 비중이 쏠렸다. 개폐업·주류 트렌드는 유용한 보조자료지만, 유동·소비 특성 파악을 대신하거나 모든 후속 작업의 선행조건이 되어서는 안 된다.

## 5. 다시 잡는 실행 순서

### 1단계: 카드 제공 범위 확인과 첫 현장 답사를 병행

- 카드: 공간 단위·경계 맞춤 집계 가능성·기간·시간대·업종 코드·금액과 건수 정의·실측/추정 여부·소수집계 처리·보고 가능한 집계 수준을 확인한다. 현재 상품이 읍면동뿐이면 동 배경 분석으로 역할을 확정한다.
- 경계: 사용자가 그린 범위를 유지하며 포함·제외 이유를 기록한다. 500m 반경 783개와 사용자 경계 534개는 경계 차이이며 시계열 감소가 아니다.
- 답사: A/B/C 후보 지점을 확정하고 기존 조사 서식으로 통행·영업·불편·방문 목적을 기록한다. 야간 전략을 검토한다면 18시 관찰만으로 야간 전체를 설명하지 않고 해당 시간대 관찰을 추가한다.
- 담당 부서의 기존 사업 위치·기간, 활용 가능한 사업 수단과 실행 주체를 정리한다. 전략의 현실성을 판단할 입력이다.

### 2단계: 실제 이용·소비의 기준선 작성

- 현장: 지점×조사일×시간대의 통과 건수, 영업 상태, 관측 불편, 응답자의 방문 목적과 이용 특성. 대표성 한계를 표시한다.
- 카드: 확보되는 동일 공간 단위에서 월별 금액·건수·건당 결제금액, 업종·시간대·연령·유입지역 구성을 집계한다. 건당 금액은 고객당 지출이 아니다.
- 비교: 전년 동월과 실제 비교지역을 사용하되, 비교지역은 자료 일관성·업종 구조·대학 영향 등 사전 조건으로 선정한다. 주안·신기는 기존 후보라는 이유만으로 대학가의 대조군이 되지 않는다.
- 시점: 현재 소비 제공 범위 2026.06까지와 9월 이후 현장조사는 같은 시점의 직접 검증이 아니다. 후속 시점이 확보되면 맞추고, 그 전에는 과거 소비와 현재 현장으로 나눠 해석한다.

### 3단계: 발견된 항목에 필요한 보조자료만 추가

- 특정 시기 소비 차이 → 학사일정·행사·날씨 등 대안 설명 검토. 월별 자료로 특정 시험일 효과를 추정하지 않는다.
- 점포 감소·교체 징후 → 과거 같은 계절 점포와 인허가 이력, 현장 확인. 과거 파일에 없는 점포를 곧바로 폐업으로 판정하지 않는다.
- 주점·저녁 소비 변화 → 음주·외식 장소와 빈도 등의 외부 변화 및 지역 상인·이용자 응답을 검토한다. 전국 주류 소비 변화만으로 후문 문제의 원인을 확정하지 않는다.
- 반복되는 동선 불편 → 해당 경로의 실제 보행시간·횡단·안내 상태 등 상세 조사.

### 4단계: 근거가 있는 2~3개 전략과 평가 설계

아래는 선택 조건을 보여주는 예시이며 현재 채택한 전략이 아니다.

| 확인될 근거 | 검토할 전략 | 시행 후 확인할 지표 |
|---|---|---|
| 진입부 통행과 골목 이용의 차이, 안내 불편의 반복 응답 | 연결 안내·동선 개선 | 동일 지점 통행 변화, 안내 인지·이용 불편 응답 |
| 함께 이용할 수요가 있는 업종·점포가 확인됨 | 참여 점포 간 공동 안내·연계 이용 사업 | 참여 점포 연계 이용 건수·실제 사용, 가능한 매출 자료 |
| 특정 시기 이용 수요와 실제 영업·서비스 제공의 불일치 | 시간·대상에 맞는 운영 조정 또는 소규모 시범사업 | 대상 시간의 이용·참여 점포 운영·결제 변화와 운영 비용 |

전략마다 ‘대상 구간/시간/고객, 근거, 실행 내용, 실행 주체, 비용·제약, 기대하는 변화, 사전·사후 지표, 아직 모르는 점’을 기입한다. 단순 전후 변화만으로 사업의 인과적 효과라고 부르지 않는다.

## 6. 산출물 정리

- `real_analysis.ipynb`, `briefing_eda_20260909.ipynb`: 후보 선정 당시의 기초 EDA로 보존한다. 현재 후문 범위 수치를 설명할 때는 534개 경계 결과를 사용한다.
- `outputs/inha/`: 현재 후문 공간·업종 기준자료다. 현장 대조 전 공식 상권 경계나 실제 공실 현황으로 표현하지 않는다.
- `inha_synthetic_card_demo.ipynb`: 집계·결합 개발 예제로 사용한다. 입력에 심어 둔 감소·학기 패턴을 발견한 것은 지역에 관한 연구 결과가 아니다.
- `docs/인하대후문_진단계획.md`: ‘경계 파일로 재집계가 다음 작업’이라는 문구는 이미 완료된 작업으로 갱신할 필요가 있다. 목적도 문제 검증과 함께 강점·활용 기회를 포함하도록 수정할 필요가 있다.
- 후속 본분석은 현재 현황 → 실제 이용·소비 패턴 → 문제/기회와 근거 → 실행전략 → 평가계획 순서로 구성한다.
