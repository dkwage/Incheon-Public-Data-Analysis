# 미추홀구 데이터 분석 주제 제안 ∘ 인하대학교 데이터사이언스학과

# I. 제안 개요

## 제안 목적 및 후보 상권

- 미추홀구 내 상권의 유입 여건, 업종, 소비 특성을 분석하여 활성화 방안을 도출하고자 함.

- 이를 통해 획일적인 지원이 아닌 상권의 유형에 맞는 전략의 우선순위를 제시하고자 함. 후보 상권 상권 성격 우선 검토 내용 주안역세권 및 지하상가 광역 유입형 환승 유입의 체류·소비 전환과 지하·지상 상권 연계 신기시장 일대 생활밀착형 시장-주변 점포 연계와 지원책 공백 보완 인하대역·인하대 후문·용현동 일대 청년·생활형 학기·요일별 수요와 청년층·야간 활성화 - 담당 부서와 후보 상권의 정책적 우선순위를 협의하여 분석 대상을 확정함.

# II. 활용 데이터 및 분석 방법

## 즉시 활용 가능한 공개 데이터 데이터 분석 활용 제공 위치 버스 정류장별 승·하차 인원 대중교통 기반 유입

| 잠재력 비교 | 공공데이터포털 |
|:--- |:--- |
| 상가업소·일반음식점 현황 | 업종 구성, 점포 밀도, |
| 경쟁·공백 업종 진단 | 공공데이터포털 |
| 시장·상점가·음식특화거리 | 상권 경계 설정 및 상권 | 상가업소·일반음식점 현황 업종 구성, 점포 밀도, 경쟁·공백 업종 진단 공공데이터포털 시장·상점가·음식특화거리 상권 경계 설정 및 상권 유형 구분 공공데이터포털 행정동 인구·연령 배후 주거수요와 타깃 고객 추정 공공데이터포털·국가통계 포털 신한카드 지역별매출 및 이용고객 정보 읍면동·업종·시간대·성/연령 ·유입지역별 결제건수·금액 분석 데이터안심구역(신한카드)

※ 정류장 승하차는 실제 전체 유동인구가 아닌 대중교통 기반 유입 잠재력 지표이며, 신한카드 자료는 데이터안심구역 내 분석자료임.

## 분석 방법 결합 데이터 분석 방법 진단 결과 상권 경계·연결성 보행 네트워크 서비스권· GIS 공간조인 상권 경계·정류장 연결도 유입·접근성 Hansen 접근성 지수·커널밀도추정(KDE) 유입 잠재력·접근성 격차 업종 구조 LQ·Shannon 엔트로피·Gi\* 핫스팟 과밀·공백·특화 업종 소비 수요 업종별 소비구성비·요일별 중앙값·변동계수(CV) 업종별 소비 기준선·요일별 변동 통합 우선순위 표준화 지수·AHP-TOPSIS (K-means는 보조) 우선순위·상권 유형 \* 군집분석은 표본과 데이터 품질이 충분한 경우에만 보조적으로 적용함.

# III. 전략 도출 방향

## 상권 진단 결과에 따른 활성화 전략(안) 진단 신호 전략 방향 실행 예 유입↑·소비전환↓ 통과 유입을 체류·구매로 전환 역-골목 연결 동선·공동 쿠폰 생활수요↑·업종공백 생활서비스 공백을 우선 보완 시장-골목 묶음상품·공백업종 유치 대학수요↑·시간대 변동 수요가 큰 시간대에 집중 학기·야간 공동 프로모션 업종집중↑·차별성↓ 과밀업종의 차별화·전환 업종전환 컨설팅·공동브랜딩 정책 효과 검증 사업 전후 변화로 지속·보완 판단 세분 소비자료 확보 시 DID 검증 ※ 후보 상권별로 위 진단 신호에 맞는 전략을 선택·조합함.

※ 카드 매출·이용고객 자료는 데이터안심구역 내에서 결합·분석하고, 반출은 집계·비식별 기준을 준수함.

# IV. 추진 요청 사항 및 데이터 출처

## 추진 절차 및 협조 요청 □ 후보 상권 확정 후 기본 진단, 전략 제안 순으로 추진함. 단계 주요 내용 담당 부서 협조 사항 1단계 후보 상권과 보행권 경계 확정 정책 우선순위와 대상지 의견 제시 2단계 공개 데이터 수집·정제와 기초 진단 기존 행사·환경개선·상권 지원사업 정보 공유 3단계 상권별 전략과 우선순위 제안 결과 활용 목적과 후속 검토 방향 협의
