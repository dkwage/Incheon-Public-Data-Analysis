# 실데이터 기초진단 진행 현황 및 API 안내

확인일: 2026-09-08. 후속 노트북: `../real_analysis.ipynb`.

## 완료한 작업

- 기존 공공데이터 인증키로 미추홀구 전체 점포 18,885개 완전 수집. API 응답 기준월 `202606`.
- 재래시장 15개, 버스 승하차 6,760행, 인천 지역 버스 위치 9,278행 수집.
- 원본 JSON에 인증키 없는 요청 조건·조회시각·기준월·전체 건수·완전 수집 여부 기록.
- 인천BIS 위치만 골라 모바일단축번호와 정류장명을 함께 대조. 승하차 6,760행 중 6,521행 매칭(96.46%). 미매칭 239행과 좌표 충돌 2행 별도 저장. 이 비율은 원본 전체 기준이며 미추홀구 내부 매칭률이 아님.
- 샘플의 중심좌표를 공공자료 기반 임시 중심으로 수정. 주안역은 환승정류장 2개 평균, 인하대후문은 동명 정류장 3개 평균, 신기시장은 시장 대표점 사용.
- 300m·500m·1km 각각 구 전체 대비 중분류 코드 기준 LQ와 Shannon 엔트로피 산출.
- 일평균 승하차·추정 일평균 하차 기반 접근성을 β=0.001/0.0015/0.002에서 계산. 직선거리 1km 내 매칭 정류장만 포함.
- 샘플 노트북 상단에 과거 결과의 한계 및 후속 노트북 안내 추가. 샘플 소비·TOPSIS 결과는 실데이터 분석에 사용하지 않음.

## 500m 임시 분석권 결과

| 상권 | 점포 수 | Shannon 엔트로피 | 기존 중심에서 이동 |
|---|---:|---:|---:|
| 주안역세권 | 2,154 | 3.484 | 약 583m |
| 신기시장 | 1,087 | 3.163 | 약 1,277m |
| 인하대후문 | 783 | 3.228 | 약 190m |

상권의 크기·경계·업종분류에 따라 값이 달라진다. 다양성이 높다는 이유만으로 정책적 우선순위가 높다고 해석하지 않는다. 반경별 결과는 `outputs/zone_summary.csv`, 업종별 결과는 `outputs/zone_lq.csv`에 있다. 상권 간 중첩은 허용하고 따로 집계했으며 이번 임시 중심의 1km 이내 점포에서는 중복이 관측되지 않았다.

## 기준시점과 해석 한계

- 점포: 2026년 6월(API `header.stdrYm`).
- 승하차: 2026-06-30 명세. 기존 노트북 endpoint가 이 월 자료임을 [공식 OpenAPI 명세](https://infuser.odcloud.kr/oas/docs?namespace=15048264/v1)에서 확인.
- 정류장 위치: 2025-10-31(원본 `정보수집일`). 이후 신설·이전·명칭 변경 정류장은 누락/불일치 가능.
- 시장: 제공 페이지 기준 2024-10-31. 대표점이지 시장 경계 폴리곤이 아님.
- 원형 반경은 보행권이 아니다. 주안역 지하·지상 구분과 철도 장벽, 대학 출입구, 시장 골목은 현장·지도 검토가 필요하다.
- 구 전체 점포만 분석하므로 반경 안 구 밖 점포는 제외한다. 면적당 밀도는 구 경계와 분석권 교차면적 확정 후 계산한다.
- LQ는 특화지표다. 희소 업종은 점포 수를 병기하며 5개 미만은 `small_count`로 표시한다. 과밀·공백을 단정하지 않는다.
- 버스 승하차 합은 유입인구나 고유 방문자 수가 아니다. 철도 이용객도 포함하지 않는다.
- 동별 인구는 6월·8월 자료를 확보했다. 실제 카드자료가 없어 소비전환율·공급부족·지원순위는 산출하지 않았다.

## 필요한 API·다운로드 URL

### 1. 확보 완료: 동별 연령인구 (아래는 재수집 경로)

- [행정안전부 행정동별 연령별 인구현황](https://jumin.mois.go.kr/ageStatMonth.do): 미추홀구 하위 행정동, 2026년 6월, 연령별 인구를 파일로 내려받는 경로. 일회성 분석은 API 키 없이 파일 확보를 우선한다.
- [KOSIS 통계표: 행정구역(읍면동)별/5세별 주민등록인구](https://kosis.kr/statHtml/statHtml.do?orgId=101&tblId=DT_1B04005N): 비교 가능한 월·하위 행정동 선택.
- [KOSIS OpenAPI 신청·개발 가이드](https://kosis.kr/openapi/): 자동 수집이 필요하면 별도 인증키 신청. 공공데이터포털 키와 별개.

필요 필드: 기준월, 행정동 코드·명, 연령구간, 성별 또는 남녀합계, 인구수. 행정동 인구를 상권 인구로 그대로 이름만 바꿔 쓰지 않는다. 먼저 상권과 연결되는 행정동의 배후수요 참고표를 만들고, 정확한 보행권 인구가 필요하면 공간경계·소지역 인구를 추가한다.

### 2. 이미 연결 완료: 상가·버스·시장

| 자료 | 공식 페이지 | 이번 사용 |

| 소상공인시장진흥공단 상가(상권)정보 API | https://www.data.go.kr/data/15012005/openapi.do | 기존 키로 구 전체 점포 수집 성공 |
| 국토교통부 전국 버스정류장 위치정보 | https://www.data.go.kr/data/15067528/fileData.do | 기존 키로 인천 필터 수집 성공 |
| 인천광역시 정류장별 이용승객 현황 | https://www.data.go.kr/data/15048264/fileData.do | 기존 키로 수집 성공 |
| 미추홀구 재래시장 | https://www.data.go.kr/data/15087058/fileData.do | 기존 키로 수집 성공 |

점포 호출 endpoint: `https://apis.data.go.kr/B553077/api/open/sdsc2/storeListInDong`

조건: `divId=signguCd`, `key=28177`, `pageNo`, `numOfRows=1000`, `type=json`, `serviceKey`.

인천 위치자료 조건: `cond[도시명::LIKE]=인천`. 페이지 한도에 도달하면 부분 자료를 정상 수집으로 저장하지 않는다.

### 3. 선택: 장소 대표점·주소 정밀 확인

- [카카오 Local API 공식 문서](https://developers.kakao.com/docs/ko/local/dev-guide): 키워드 검색·주소 좌표 변환. 실제 역 출입구·후문·거리 대표점을 더 정밀하게 검토할 때 사용. 별도 REST API 키가 필요하며 이번 분석에는 사용하지 않았다.
- 지금은 공공 정류장 좌표와 시장 대표점을 확보했으므로 카카오 키 신청이 현재 기초분석을 막지는 않는다.

### 4. 소비 분석: 신한카드 자료

제안서의 데이터안심구역 자료는 이번 공개 API 수집 대상이 아니다. 실제 이용자료의 공간단위(행정동/격자/맞춤상권), 기준기간, 업종코드, 날짜·요일·시간대, 결제금액·건수, 성·연령·유입지역 집계 가능 여부를 확인해야 한다. 맞춤 상권별 분리가 안 되면 소비 분석의 공간단위를 재설계한다.

## 실행 및 산출물

프로젝트의 `Commercial district analysis` 폴더에서:

```sh
.venv/bin/python collect_real_data.py
```

이후 같은 가상환경 커널로 `real_analysis.ipynb` 전체 실행. 수집기는 `DATA_GO_KR_SERVICE_KEY` 환경변수를 우선 사용하고, 없으면 기존 sample 노트북의 키를 메모리에서 재사용한다. 새 파일에는 키를 복사하지 않는다. 동일 조건의 완전 수집 스냅샷이 있으면 재사용하며 갱신 수집은 기존 스냅샷을 별도 보관한 뒤 수행한다.

- `data/raw/*.json`: 재현용 원본 스냅샷.
- `outputs/zone_centers.csv`: 임시 중심·출처·변경거리.
- `outputs/zone_summary.csv`: 반경별 점포 수·다양성.
- `outputs/zone_lq.csv`: 구 전체 기준 업종별 LQ.
- `outputs/zone_stores.csv`: 반경별 포함 점포 목록.
- `outputs/zone_review.png`: 기존/수정 중심과 점포 분포 그림(배경지도 없음).
- `outputs/zone_review.geojson`: GIS에 불러올 임시 대표점·500m 원.
- `outputs/bus_matched.csv`, `bus_unmatched.csv`, `bus_ambiguous_locations.csv`: 결합 감사자료.
- `outputs/bus_accessibility_provisional.csv`: 감쇠계수별 버스 접근성 참고표.

노트북 8개 코드 셀 실행 완료. 완전 수집·점포 ID 유일성·지역/좌표·LQ 기준집단·반경 포함관계·버스 조인 무증식 검증 통과. 지도 그림 육안 확인 완료.

다음 작업: 임시 분석권 지도 검토 → 동별 배후수요와 업종구조 함께 해석 → 카드자료 단위 확인 및 실제 소비 분석. 보행권·면적당 밀도·정책 우선순위는 아직 미완료다.


## 2026-09-08 인구자료 연결 완료

사용자가 갱신한 `data/202606_202606_*.csv`, `data/202608_202608_*.csv`를 사용했다. 두 파일 모두 CP949, 22행 × 310열이며 미추홀구 합계와 21개 동, 남녀 및 합계, 0~99세·100세 이상을 포함한다. 앞서 확인했던 다운로드 범위 부족은 해결됐다. KOSIS API 재수집은 필요하지 않아 중단했으며, 제공된 인증키는 코드나 노트북에 저장하지 않았다.

- 최신 진단: 2026년 8월. 점포·승하차와 동시점 비교: 2026년 6월.
- 정규화 결과: 13,332행. 각 지역의 연령합계=총인구, 남+여=계, 21개 동 합계=구 합계 검증 통과.
- 미추홀구 총인구: 6월 418,211명 → 8월 419,123명, +912명(+0.218%).
- 8월 구 전체 20~39세 107,077명(25.55%), 65세 이상 93,218명(22.24%). 20~39세는 분석용 구간이며 법정 청년 기준이 아님.
- 500m 내 점포 행정동 코드를 인구 행정동 코드와 연결하고 명칭도 대조했다. 점포가 거의 없는 동도 누락 없이 표시한다. 관련 동 전체 인구를 상권 인구로 합산하거나 점포비중으로 배분하지 않았다.

| 주요 관련 동 | 연결 상권 | 8월 동 전체 인구 | 20~39세 비중 | 65세 이상 비중 |
|---|---|---:|---:|---:|
| 주안1동 | 주안역세권 | 19,903 | 35.70% | 16.12% |
| 주안7동 | 신기시장 | 12,020 | 20.00% | 30.87% |
| 용현1.4동 | 인하대후문 | 17,171 | 36.85% | 25.93% |

각 상권의 500m 내 점포가 가장 많이 속한 동을 예시로 표시했다. 해당 동이 상권 전체를 대표한다고 가정하지 않으며, 다른 관련 동도 결과 파일에 포함했다. 주민등록인구는 실제 방문객·학생 생활인구와 다르다.
