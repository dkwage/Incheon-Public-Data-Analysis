# 인하대 후문 탐색 현장조사

## 목적과 조사 범위

상권이 어렵다고 전제하지 않는다. 점포 데이터와 현장이 일치하는지, 이용·운영상 반복되는 문제가 있는지 확인한다.
첫 조사는 문제 후보를 찾는 탐색 조사이며 전체 고객·상인의 대표 표본이 아니다.

## 1. 사전 답사 1회: 지점과 동선 고정

사용자 경계를 따라 걸으며 도로변 점포의 포함 여부를 확인한다. 지도에서 ‘경계 10m 이내 확인 대상’을 켜고 실제 점포 입구·건물 위치를 확인한다.
이후 다음 세 유형에서 관찰 지점을 한 곳씩 정한다. 아래는 후보 구간이며 도로 통행·안전과 실제 연결을 확인한 뒤 좌표를 기록한다.

| 지점 | 후보 구간 | 관찰 목적 |
|---|---|---|
| A | 후문 맞은편 인하로의 상권 진입부 | 대학·도로에서 상업거리로 이어지는 통행 |
| B | 경인남길30번길·인하로77번길 중 점포 밀집 구간 | 내부 음식·오락 거리 이용 |
| C | 인하로47번길 또는 인하로91번길의 내부 골목 | 중심 거리와 다른 구간의 영업·생활 이용 |

현재 점포 주소상 경인남길30번길 135개, 인하로 114개, 인하로77번길 94개다. 점포 수가 많다는 이유로 통행이 많거나 문제가 있다고 판단하지 않는다.
각 지점에서 계수할 가상 횡단선, 두 방향, 관찰자 위치를 지도에 고정한다. 지점별 50~100m 관찰 구간의 양 끝도 정한다.
인도·출입구를 막지 않는 위치를 선택하고 같은 지점으로 재방문할 수 있게 시설 중심 사진을 남긴다.

## 2. 반복 관찰: 평일 2일 + 토요일 1일

처음에는 행사·시험·공휴일이 아닌 평상시 학기 중에 조사한다. 학사일정과 실제 행사 여부를 함께 확인한다.
제안 시간은 점심 12:00~12:15, 저녁 18:00~18:15이며 사전 답사에서 필요하면 조정한 뒤 고정한다.

- 3명이 가능하면 A/B/C에 한 명씩 배치해 같은 시간에 15분 관찰한다. 총 3지점 × 3일 × 2시간대 = 18개 관찰 기록.
- 1~2명이면 지점을 순차 관찰하되 실제 시작·종료 시간을 적고 재방문 때 같은 시각을 맞춘다. 지점 간 차이에 시간 차이가 섞인다는 한계를 보고한다.
- 비·행사 등 조건이 달라지면 삭제하지 말고 표시하고, 가능하면 비슷한 조건에서 추가 관찰한다.
- 현재 카드자료는 2026년 6월까지다. 9월 이후 현장을 6월 카드와 같은 시점의 검증으로 표현하지 않는다.

### 관찰 단위와 항목

| 항목 | 기록 방법 |
|---|---|
| 통행 | 정해진 선을 통과하는 사람을 방향별로 계수. 재통과 포함 ‘통과 건수’, 고유 방문자 수 아님 |
| 머무름 | 시작·5분·10분 시점에 정한 공간의 정지·대기 인원 기록. 실제 체류시간은 별도 추적 없이는 추정하지 않음 |
| 영업 상태 | 구간 점포별 영업 중 / 닫힘 / 확인 불가. 닫힘만으로 폐업 판정 금지 |
| 빈 점포 후보 | 임대 표지, 내부 비움 등 관측 근거를 기록하고 재방문·관리자 확인 전 확정하지 않음 |
| 접근 불편 | 횡단 대기·실제 보행시간·적치물·우회·보도 장애의 위치와 반복 여부 |
| 외부 조건 | 날짜·요일·시간·관찰분·날씨·비·행사·시험·공사 여부 |

공실을 세려면 상업용 공간의 단위를 먼저 정한다. 첫 조사에서는 지정 구간 1층 전면 점포를 대상으로 하며 상층부·주택을 분모에 넣지 않는다. ‘확인 불가’를 남긴다. 구간의 결과를 534개 전체 점포의 공실률로 확장하지 않는다.

## 3. 짧은 의견 조사

관찰 계수와 인터뷰를 동시에 맡지 않는다. 계수를 마친 뒤 자발적 참여자를 대상으로 진행한다.
제안 목표는 상인 10~15곳, 이용자 20~30명이며 문제 후보 탐색용이다. 거절·응답 수와 위치·시간대를 기록한다.
한 업종·한 거리·한 시간대에만 몰리지 않도록 음식점·카페·소매·서비스와 A/B/C 구간에서 나눠 접촉한다.

### 상인 질문 (약 5분)

1. 이곳에서 영업한 기간과 보통 영업시간은 어떻게 되나요?
2. 최근 1년 영업 상황은 좋아짐·비슷함·어려워짐 중 어느 쪽인가요? 그렇게 판단한 근거는 무엇인가요?
3. 바쁜 달·한산한 달, 요일·시간대는 언제인가요? 학기·방학 차이가 있나요?
4. 현재 겪는 어려움이 있다면 무엇인가요? 특별한 어려움이 없다는 응답도 기록합니다.
5. 그 어려움의 원인은 무엇이라고 보나요? 관측한 사실과 추측을 구분해 기록합니다.
6. 이미 해본 대응과 결과가 있나요?

정확한 매출·개인정보를 요구하지 않고, 자발적으로 제시된 변화도 ‘상인 자기보고’로 표시한다. 폐업한 업소의 사정은 현재 영업 상인 인터뷰만으로 대표할 수 없다.

### 이용자 질문 (약 2분)

1. 오늘 이곳에 온 주된 목적은 무엇인가요?
2. 방문 빈도와 주로 오는 시간대는 어떻게 되나요?
3. 오늘 이용한/이용할 점포가 있나요? 이용하지 않았다면 이유가 있나요?
4. 이곳 이용에서 불편한 점이 있나요? 없다면 없다고 기록합니다.
5. 대학 재학·근무, 인근 거주·근무, 그 외 중 관련이 있는 항목을 선택할 수 있나요? 응답하지 않아도 됩니다.

학생·연령·주민 여부를 외모로 추정하지 않는다. 이름·연락처는 수집하지 않는다.

## 4. 기록과 판단

`outputs/inha/field_observation_template.csv`, `field_store_template.csv`, `field_interview_template.csv`를 사용한다. 모두 빈 서식이며 조사 결과가 아니다.
사진은 시설 중심, 기록에는 사실·해석·추가 확인을 구분한다.

조사 후 ‘문제 후보 / 몇 회·어디서 관찰 / 상인·이용자 근거 / 다른 설명 / 추가 데이터 / 판단’을 한 행으로 정리한다.
예: 저녁에 닫힌 점포가 많음 → 휴무·영업시간인지 확인 → 다른 평일 저녁 재방문 → 실제 반복적인 이용 불편 여부 확인.
탐색 결과는 ‘문제 근거 있음 / 뚜렷한 근거 없음 / 판단 유보’로 정리한다. 미리 정한 근거 없는 수치 기준으로 위험 상권 점수를 만들지 않는다.
